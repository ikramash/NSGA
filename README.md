# Nonmonotone Line Search Algorithms for Unconstrained Optimization

## Description
This repository provides Python implementations of three nonmonotone line search algorithms for unconstrained optimization, including a proposed method combining average function values with the Barzilai–Borwein gradient method.

## Algorithms
- **Algorithm 1:** Nonmonotone line search based on the maximum of recent function values.
- **Algorithm 2:** Nonmonotone line search based on average function values.
- **Algorithm 3:** Proposed nonmonotone line search combining average function values with the Barzilai–Borwein gradient method.

## Requirements
Python 3 and the necessary scientific computing libraries.

## Usage
The code can be used to perform numerical experiments and evaluate the performance of the modified nonmonotone line search technique
and its applications to unconstrained optimization problems.
